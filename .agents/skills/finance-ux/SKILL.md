# Personal Finance UX

Read `constitution.md` Product Principles and UX Experience Standards, then
`docs/PRODUCT-UX-FLOW.md`. Use `sdd-discovery` and `sdd-specify` when the
feature follows the project's SDD flow. The constitution owns the discovery
gate; this skill does not redefine its size threshold.

- Name the user's moment, time horizon, and decision before designing stores
  or routes. State what the user sees first at 390×844.
- Present at least two concrete UI options with a recommendation and tradeoffs
  during discovery. Describe the feedback loop and benefit shown to the user.
- Review card hierarchy, semantic status colors, useful empty states, context
  for non-obvious metrics, mobile overflow, and effective touch targets
  against the constitution.
- Read `finanzas ej/` and the benchmark links in `docs/PRODUCT-UX-FLOW.md`
  when comparing products; verify live references before relying on them.
