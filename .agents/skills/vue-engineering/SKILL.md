# Personal Finance Vue Engineering

Read `AGENTS.md` and `constitution.md` first. Match the existing Vue 3,
Pinia, Vite, and Tailwind conventions. This skill is project-scoped; do not
load React/Next.js guidance for Vue work.

- For tests or changed behavior, read [testing.md](references/testing.md).
- For user-facing design or discovery, use `finance-ux`.
- For Colombian payroll or tax logic, use `colombia-payroll`.

Verify with the commands in `AGENTS.md`; add the repository's coverage and
E2E gates when their documented scope applies.
